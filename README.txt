NAKAVELI WEBSITE DEMO

Folder contents
- index.html       Main homepage and page structure
- css/style.css    Colours, typography, layout and responsive styles
- js/products.js   Product details, prices, categories and size options
- js/main.js       Product filters, cart, quantity controls and demo checkout
- images/          Add your real product photos here

RUN IN VS CODE
1. Extract NakaveliWebsite_Source.zip.
2. In VS Code, choose File > Open Folder and select NakaveliWebsite.
3. Open index.html in a browser, or install the Live Server extension and choose Open with Live Server.
4. Edit and save files, then refresh the browser.

EDIT PRODUCTS
Open js/products.js. Change each product's name, description, category, price, colour, tag and print text. Use category "tees" or "hoodies". Give each product a unique id.
Change the sizes array at the bottom to show only sizes you actually stock.

EDIT DESIGN
Open css/style.css. At the top, change --bg, --text, --muted and --accent for the main colours.

IMPORTANT
This is a front-end demo. Cart contents are not saved after refresh. It does not process payments, save real orders, manage live inventory or arrange delivery. Do not use it to collect payment details or sensitive customer information.
